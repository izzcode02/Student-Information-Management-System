## Description
The System Information Management System is a comprehensive Flutter application designed to manage various functionalities including user authentication, personal note management, access to device tools, and data integration with external APIs.

## How to Clone this Repository
To clone this repository, follow these steps:

1. Open a terminal on your local machine.
2. Use the following command to clone the repository:
   ```bash
   git clone <repository-url>
   ```
3. Navigate to the project directory:
   ```bash
   cd <repository-folder>
   ```

## How to Run this Flutter Application
To run the application, ensure you have Flutter installed and set up on your system. Then, follow these steps:

1. Open the terminal in the project directory.
2. Fetch all dependencies by running:
   ```bash
   flutter pub get
   ```
3. Ensure a device (emulator or physical device) is connected.
4. Run the application using the following command:
   ```bash
   flutter run
   ```

## Functionality
The application includes the following features:

### Authentication
- User login and registration using email and password.
- Google Sign-In integration for seamless authentication.

### Database Integration
- Firebase Cloud Firestore is used to store and manage user data securely.

### Profile Management
- Users can create and manage their profiles.

### Personal Notes
- A message notes feature is available for users to jot down personal notes.

### Tools
The application provides access to various device tools:
- **Accelerometer**: Access device motion sensors.
- **Camera and Video**: Capture photos and record videos.
- **QR Code Scanner**: Scan QR codes for quick information retrieval.
- **GPS and Geolocation**: Utilize geolocation features powered by the Nominatim API.
- **Microphone**: Record audio via the device microphone.
- **Bluetooth**: Integrate with Bluetooth-enabled devices.

### External Data Integration
- **Student List API**: Displays a list of students fetched from a random API.
- **Books List**: Provides a list of books using a RESTful API built with Laravel.
